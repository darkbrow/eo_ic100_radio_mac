# FM 라디오 (맥용, EO-IC100)

아이폰으로 이동한 이후 용도를 잃어버린 갤럭시 일부 기종 전용 튜너 내장 삼성 USB-C 이어폰 EO-IC100을 맥에서 사용해 볼까 하고 Claude에 작성을 시킨 결과물입니다.
[kjy00302/eo-ic100_radio](https://github.com/kjy00302/eo-ic100_radio) 작업을 참고하여 맥용 앱으로 작성했습니다(물론 claude가 한 겁니다).

삼성 갤럭시 FM 라디오 앱의 디자인을 맥으로 옮긴 Swift/SwiftUI 앱입니다. EO-IC100 이어폰의 FM 칩을
[`eo-ic100_radio`](https://github.com/kjy00302/eo-ic100_radio) 파이썬 PoC와 같은 USB 명령으로 제어합니다. 가로 화면에 맞춰 왼쪽에 튜너, 오른쪽에 채널 목록,
아래에 타임머신/녹음 막대를 둡니다.

## 요구사항
- macOS 13 이상, Xcode(또는 Command Line Tools)의 Swift 5.9 이상
- 의존 라이브러리는 모두 macOS 내장입니다: SwiftUI, AVFoundation, CoreAudio, IOKit, IOUSBHost

## 빌드와 실행
```
swift run                # 빠른 실행 (마이크 권한 요청이 터미널 앱 이름으로 뜹니다)
./make_app.sh            # build/FMRadio.app 생성 (권장)
open build/FMRadio.app
```
`sudo`는 필요 없습니다. 이 앱은 USB 인터페이스를 점유하지 않고 기본 컨트롤 엔드포인트로만 명령을 보냅니다.

## 앱 아이콘
삼성 FM 라디오 앱 아이콘(`Resources/AppIcon-original.png`)을 씁니다.
- 아이콘 원본은 삼성의 디자인입니다. 개인 용도로 쓰는 것과 달리 앱을 다른 사람에게 배포할 때는 별도의 아이콘으로 바꾸세요.

## 화면 크기와 모드
- **화면 모드**: 기본은 **다크**입니다. 라이트는 갤럭시 라디오 라이트 화면 캡처에서 읽은 색을 썼습니다
  (배경 `#F6F6F6`, 카드 `#FCFCFC`, 글자 `#202020`, 강조 `#45AADC`, 별 `#F3B900`, 즐겨찾기 원 `#BABABA`).
  바꾸는 곳: 설정(⌘,) > 화면. 고르면 메인 창, 설정 창, 시트, 메뉴에 바로 적용되고(AppKit의 앱 모양을 직접 지정),
  "시스템"을 고르면 macOS의 모드를 따릅니다.
- 색은 `Views/Theme.swift`의 `Palette`(다크/라이트 각각)에 모아 두었고, 뷰는 `@Environment(\.palette)`로 받아 씁니다.

## 동작 방식
1. 전원 버튼을 누르면 이어폰을 **녹음 모드**로 바꿉니다. 이 모드에서만 라디오 오디오가 USB 입력으로 나옵니다.
2. 입력(이어폰) → [타임머신 저장소] → 링 버퍼 → 선택한 출력 장치로 재생합니다.
   AVAudioEngine은 입력과 출력에 서로 다른 장치를 쓸 수 없어 엔진 두 개를 링 버퍼로 연결했습니다.
3. 소리가 작을 때를 위해 설정의 **음량 보정**(0~24dB)과 피크 리미터를 둡니다.
4. 종료하거나 이어폰을 뽑으면 라디오 전원을 끕니다.

## 기능
### 음소거
튜너 카드 오른쪽 위의 스피커 버튼 또는 `M`. 출력만 끊고, 타임머신 기록과 녹음에는 영향을 주지 않습니다.

### 타임머신 (일시정지 / 되감기)
- 라디오를 켜는 동안 최근 N분(설정: 5/15/30/60분, 기본 15분)의 오디오를 임시 파일에 순환 저장합니다.
  16비트 스테레오 PCM이라 분당 약 11.5MB를 쓰고, 라디오를 끄면 지워집니다.
- 아래 막대: 15초 뒤로/앞으로, 일시정지/재생, LIVE로 돌아가기, 타임라인 슬라이더.
- 일시정지한 자리에서 이어 들을 수 있고, 라이브를 따라잡으면 자동으로 LIVE로 돌아갑니다.
- **방송국을 바꾸면 이전 방송의 기록은 버립니다.** 채널 찾기와 AF 확인 중에는 기록을 건너뜁니다.

### 녹음
- `녹음` 버튼(또는 `R`): 지금부터 AAC(m4a, 192kbps, 스테레오)로 저장합니다. 되감기 중에도 라이브가 녹음됩니다.
- 저장 버튼: 타임머신 버퍼의 **지난 1/5/15/30/60분**을 파일로 저장합니다 (설정한 버퍼 길이 이내).
- 기본 저장 폴더는 `~/Music/FM 라디오`이며 설정에서 바꿀 수 있습니다.

### RDS 방송 정보
- 튜너 카드에 방송국 이름(PS), 프로그램 종류(PTY), TP/TA 표시, 라디오 텍스트(RT)를 보여줍니다.
- 해석하는 그룹: PI, 그룹 0(PS, TA, 음악/음성, AF), 그룹 2A/2B(라디오 텍스트).
- **방송국별 저장 정보**: 주파수마다 마지막에 받은 RDS 정보를 저장해 두고(앱을 껐다 켜도 유지),
  다른 주파수로 갔다가 돌아오면 새 정보가 들어오기 전까지 저장된 정보를 흐리게 `이전 수신` 표시와 함께 보여줍니다.
  새 정보가 일부만 들어온 동안에는(PS 조각이 덜 모였거나 라디오 텍스트가 끝까지 안 왔을 때) 빈 부분을
  저장된 정보로 채우며, PI가 같을 때만 섞습니다. 그 주파수의 방송국이 달라졌으면(PI가 다름) 저장된 정보를 쓰지 않습니다.
  설정 > RDS의 "저장된 RDS 정보 지우기"로 비울 수 있습니다.
- 방송국이 RDS를 송출하지 않으면 "RDS 수신 대기 중…"만 표시됩니다.
- 한계: RDS 문자 집합 중 ASCII 범위만 표시합니다. PTY 이름은 RDS 표준(유럽) 기준입니다.

### AF (대체 주파수)
- RDS의 AF 목록(방식 A)을 읽어 `AF n` 배지로 보여주고, 메뉴에서 대체 주파수로 직접 이동할 수 있습니다.
- **AF 자동 전환**(설정, 기본 꺼짐): RDS를 받다가 4초 넘게 끊기면 대체 주파수를 차례로 맞춰 보고,
  **PI가 같은 방송**이면서 수신이 가장 센 주파수로 옮깁니다. 확인하는 동안 잠깐 소리가 끊깁니다.
- `A` 키로 지금 바로 확인할 수도 있습니다.

### 볼륨 키와 시스템 출력 장치
- 맥의 볼륨 키와 HUD, 이어폰의 볼륨 버튼은 **시스템 기본 출력 장치**만 조절합니다. 앱이 소리를 다른 장치(Mac 스피커,
  설정에서 고른 출력 장치)로 보내면, 키가 소리가 나지 않는 이어폰의 볼륨을 조절하게 됩니다.
- 그래서 라디오가 켜져 있는 동안 **시스템 기본 출력을 재생 중인 장치로 맞춥니다.** 라디오를 끄거나, "Mac 스피커로 재생"을
  해제하거나, 앱을 종료하면 원래 장치로 되돌립니다. 설정 > 오디오에서 끌 수 있습니다.
- 부작용: 맞춰 둔 동안은 다른 앱의 소리도 그 장치로 나옵니다 (시스템 출력이 바뀌는 것이므로).
- 안전장치: 사용자가 그 사이에 시스템 출력을 직접 바꾸면 더 이상 건드리지 않고 되돌리지도 않습니다.
  앱이 비정상 종료되어 바뀐 채 남았으면 다음 실행 때 되돌립니다. 이 동작으로 오디오 엔진이 멈추면 같은 설정으로 다시 시작합니다.

### 표시명 (채널/즐겨찾기 이름)
- 주파수마다 원하는 이름(최대 24자)을 붙일 수 있습니다. 채널 목록에는 이름 아래에 주파수가, 즐겨찾기 원 아래에는 이름이,
  재생 중 제목에는 주파수 대신 이름이 표시됩니다.
- 지정하는 방법: 채널 행이나 즐겨찾기 원, 큰 주파수 숫자를 **우클릭 > 표시명 지정…**, ⋮ > 편집 모드의 연필 버튼,
  또는 `⌘E`(현재 주파수). 이름을 붙인 주파수는 채널 목록에도 자동으로 추가되고, 목록에서 삭제하면 이름도 같이 지워집니다.
- 이름은 앱을 껐다 켜도 유지됩니다. RDS 방송국 이름(PS)과는 별개입니다.

## 삼성 앱과의 대응
| 삼성 앱 | 이 앱 |
|---|---|
| 전원 버튼, "라디오를 켜세요." 안내 | 같음. 이어폰이 없으면 "EO-IC100이 연결되지 않았습니다." |
| 지금 재생 중 + 큰 주파수 + 눈금자(86–110) | 같음. 눈금자는 끌어서 조정 |
| 좌우 화살표 | ±0.1MHz |
| 채널 / 즐겨찾기 탭, 별표 | 같음 |
| 채널 찾기(자동 찾기 대화상자) | 같음 (맥에서 동작 확인) |
| ⋮ 메뉴: 편집, 스피커로 재생 | 편집, "Mac 스피커로 재생" |
| 라디오 설정: 자동 끄기 타이머, 권한, 라디오 정보 | 설정 창(⌘,) + 출력/입력 장치, 음량 보정, 타임머신, 녹음, RDS, FM 대역, 진단 |
| 홈 화면에 추가, 리마인더에 추가, 문의하기 | 맥에 해당 기능이 없어 뺐습니다 |

## 키보드 단축키 ("라디오" 메뉴)
⌘↩ 전원 · M 음소거 · ←/→ ±0.1MHz · ⇧←/⇧→ ±1.0MHz · ⌘←/⌘→ 이전/다음 채널 · ⌘F 채널 찾기 ·
Space 일시정지/재생 · ⌥←/⌥→ 15초 뒤로/앞으로 · L 라이브 · R 녹음 · A AF 확인 · ⌘E 표시명 지정 · ⇧⌘S 맥 스피커로 재생

## 검증 상태
**맥 실제 장치로 확인된 것**
- 빌드, 이어폰 인식(처음 실행 때 권한 팝업 승인 필요), 전원/튜닝, 오디오 재생
- 채널 찾기, 재생 중 소리 끊김 없음
- 뮤트, 타임머신, 녹음
- 표시명 지정, View 메뉴 제거
- 화면 모드(다크/라이트/시스템): 설정에서 바꾸면 메인 창, 설정 창, 메뉴에 바로 적용됨
- 시스템 출력 맞추기: Mac 스피커로 재생할 때 볼륨 키/이어폰 버튼/HUD가 스피커를 조절하고, 해제하거나 끄면 원래 장치로 돌아옴
- RDS: 녹음 모드에서도 일부 방송국의 RDS가 수신되어 표시됨 (RDS를 송출하지 않는 방송국은 당연히 표시되지 않음)

## 문제가 생기면
- **이어폰이 인식되지 않음**: 꺼진 화면에 "EO-IC100이 연결되지 않았습니다."가 보이면 USB 탐색 단계의 문제입니다.
  설정(⌘,) > 진단에서 앱이 보는 USB/오디오 장치 목록을 확인하세요. `* 04e8:a05b ...`처럼 `*`가 붙은 줄이 있어야 합니다.
  `ioreg -r -c IOUSBHostDevice -l -w0 | grep -E '"idVendor"|"idProduct"|USB Product Name'`로도 확인할 수 있습니다.
- **RDS가 계속 "수신 대기 중"**: 먼저 그 방송국이 RDS를 송출하는지가 문제입니다. 설정(⌘,) > 진단 > "인식 상태 자세히 보기"의 RDS 줄로 가릅니다.
  라디오를 켜고 10~20초 기다린 뒤 확인하세요.
  - `RDS 칩 상태: 꺼짐` → 설정에서 RDS를 껐다 켜 보세요.
  - `조회 응답 종류`의 RDS가 0 → 칩이 RDS 그룹을 보내지 않는 것입니다. 보통 방송국이 RDS를 송출하지 않는 경우입니다.
  - RDS 그룹의 `오류`만 늘어남 → 신호가 약해서 오류 없는 그룹이 없는 것입니다.
  - `정상`이 늘어나는데도 대기 중 → 앱의 해석/표시 문제이니 "마지막 그룹(A B C D)"과 "마지막 응답 12바이트"를 알려주세요.
  켤 때 팝 소리가 날 수 있어 RDS는 오디오를 시작하기 전에 설정합니다.
- **되감기가 안 됨**: 설정에서 타임머신 버퍼가 "사용 안 함"인지, 라디오를 다시 켰는지 확인하세요.
- **USB 래퍼 컴파일 에러**: `BesUSB.m`의 `initWithIOService:` 또는 `sendDeviceRequest:` 부분을 확인하세요.
